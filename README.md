# Tailwind CSS v4 Template

A simple and reusable Tailwind CSS v4 starter template for static web projects.

## Features

* Tailwind CSS v4
* Organized project structure
* Development and build scripts
* Git and GitHub ready

## Project Structure

```text
src
│
├── index.html
├── css
│   └── input.css
├── js
│   └── main.js
├── assets
│   ├── images
│   ├── icons
│   └── fonts
└── pages

dist
└── output.css
```

## Installation

Install dependencies:

```bash
npm install
```

## Development

Start Tailwind in watch mode:

```bash
npm run dev
```

## Build

Generate the production CSS file:

```bash
npm run build
```

## GitHub

Clone the repository:

```bash
git clone https://github.com/farzadjamifar/tailwind-v4-template.git
```
